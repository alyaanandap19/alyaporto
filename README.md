# Alya Ananda Putri — Portfolio (Scaffold)

This repository is the initial scaffold for a personal portfolio built with React + Vite + Tailwind CSS.

Quick start:

1. Install dependencies:

```bash
npm install
```

2. Run development server:

```bash
npm run dev
```
